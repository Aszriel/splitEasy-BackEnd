# SplitEasy - Backend API

API *backend* untuk aplikasi **SplitEasy**, platform untuk mencatat pembagian pengeluaran grup dan penyelesaian utang (*group expense splitting*). Dibangun menggunakan lingkungan Node.js dengan framework Express.js.

## 🚀 Teknologi yang Digunakan

- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB
- **Environment:** dotenv untuk manajemen variabel lingkungan

## 📁 Struktur Folder Utama

```text
backend/
├── src/            # Kode utama aplikasi (Controllers, Models, Routes, dll)
├── tests/          # File pengujian (Testing)
├── .env.example    # Contoh variabel lingkungan
├── .gitignore      # Daftar file yang diabaikan Git
└── package.json    # Konfigurasi dependensi npm
